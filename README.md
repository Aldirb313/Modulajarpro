# Modulajarpro
Modulajarpro adalah platform AI untuk guru yang secara otomatis membuat modul ajar, LKPD, soal, presentasi, media interaktif, dan asesmen dalam hitungan menit. Dengan konsep "Guru Mengajar, AI Menyiapkan Semuanya", guru dapat menghemat waktu hingga 90% dan meningkatkan kualitas pembelajaran.
